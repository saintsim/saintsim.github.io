# saintsim.github.io

Weather app using Open Meteo API (https://open-meteo.com/). It uses TypeScript and Vite as the build tool.

If a weather update fails (HTTP error such as 403/429, timeout after 15s, or network error), the reason is shown in red in the footer and it retries every minute. Meanwhile it shows the last good forecast saved in the browser (`localStorage`), but only if that forecast is for today.

It is deployed to GitHub pages using GitHub actions with a custom action to first deploy to gh-pages.

# Build/Run Steps

```
// transpile TS -> JS (to built/)
npx tsc

// build with Vite (to dist/)
npm run build

// run locally
npm run dev
```

# Bus timetable

The Tokyo BRT timetables in `src/bus-schedule.ts` are generated by `scripts/scrape-brt.mjs`.
The *Update BRT timetable* GitHub Action runs it every Sunday morning (about 09:30 JST) and opens a PR if the timetable changed; trigger it sooner from the Actions tab with "Run workflow".
It needs *Settings → Actions → General → Allow GitHub Actions to create and approve pull requests* turned on, and GitHub pauses scheduled workflows after 60 days without repository activity (re-enable it from the Actions tab).

```
// scrape and rewrite src/bus-schedule.ts (then run `npx tsc`)
npm run scrape:brt

// test the scraper against saved copies of the stop pages (scripts/fixtures/)
npm test
```

If the site changes layout, the scrape fails instead of writing a bad timetable. Save fresh copies of the two stop pages into `scripts/fixtures/` and adjust the scraper until `npm test` passes.
