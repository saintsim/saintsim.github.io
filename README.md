# saintsim.github.io

Weather app using Open Meteo API (https://open-meteo.com/). It uses TypeScript and Vite as the build tool.

It is deployed to GitHub pages using GitHub actions with a custom action to first deploy to gh-pages.

# Build/Run Steps

```
// transpile TS -> JS (to built/)
npx tsc

// build with Vite (to dist/)
npm run build

// run locally
npm run dev
```

# Bus timetable

The Tokyo BRT timetables in `src/bus-schedule.ts` are generated by `scripts/scrape-brt.mjs`.
The *Update BRT timetable* GitHub Action runs it every Sunday morning (09:00 JST) and opens a PR if the timetable changed; trigger it sooner from the Actions tab with "Run workflow".

```
// scrape and rewrite src/bus-schedule.ts (then run `npx tsc`)
npm run scrape:brt

// test the scraper against saved copies of the stop pages (scripts/fixtures/)
npm test
```

If the site changes layout, the scrape fails instead of writing a bad timetable. Save fresh copies of the two stop pages into `scripts/fixtures/` and adjust the scraper until `npm test` passes.
